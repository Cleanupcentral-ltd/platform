UPDATE THE EXISTING CLEAN UP CENTRAL ABOUT PAGE

Modify the existing About page to incorporate the structure and content below. This is an update to the current design—not a completely new visual direction.

SOURCE-OF-TRUTH PRIORITY

Follow the project documents in this order:

1. The recently approved Clean Up Central Design System controls all visual decisions, including colours, typography, spacing, buttons, cards, imagery treatment, borders, iconography, grids and responsive behaviour.
2. This prompt controls the required About page structure and page-specific content.
3. The Website Product Design Specification controls the page’s purpose, messaging and service boundaries.
4. The existing website design should be retained wherever it does not conflict with the sources above.

If any instruction conflicts with the Design System, the Design System takes precedence.

IMPORTANT PAGE OBJECTIVE

The About page must make visitors feel:

“They have thought about the details that usually go wrong.”

Position Clean Up Central as an organised, careful and professionally operated cleaning and property-support company. Emphasise standards, accountability, communication, protection of property and clear service boundaries.

The tone should be premium but accessible, confident, clear, human and trustworthy. Avoid generic corporate language, exaggerated luxury language, fabricated claims or clichés.

GLOBAL DESIGN DIRECTION

- Preserve the bright, spacious and editorial visual style established by the Design System.
- Maintain a clean, minimalist composition with generous whitespace.
- Use black, white, warm neutral and metallic-gold styling only as specified by the Design System.
- Do not make the page dark, visually heavy or cluttered.
- Use restrained decorative details.
- Avoid excessive cards, gradients, shadows, animations or gold elements.
- Maintain strong visual hierarchy and readable paragraph widths.
- Use service-relevant, authentic-looking photography.
- Avoid generic office models, unrelated corporate portraits and heavily orange stock photography.
- Where possible, imagery should show a Clean Up Central team member, careful property preparation, a property inspection or a professionally finished space.
- Keep the global header and footer consistent with the rest of the website.
- Design desktop and mobile versions.
- Ensure the design can be recreated reliably in Wix Studio.
